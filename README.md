# 🌸 핑키 플랜 (Pinky Plan) - 파스텔 핑크 크롬 스케줄러 매뉴얼

## 🔤 깃허브(GitHub) 영어 버튼 ➔ 한글 1:1 번역 안내표

깃허브 화면에서 당황하지 않도록, 자주 나오는 영어 버튼을 알기 쉽게 풀어드립니다!

| 영어 버튼 / 단어 | 한국어 뜻 | 버튼 위치 및 하는 일 |
| :--- | :--- | :--- |
| **Sign up** | **회원가입** | 우측 상단 검은색 버튼 (처음 가입할 때 클릭) |
| **Sign in / Log in** | **로그인** | 우측 상단 글씨 (이미 아이디가 있을 때 클릭) |
| **New** | **새로 만들기** | 왼쪽 상단 초록색 버튼 (내 스케줄 보관함 만들 때) |
| **Repository name** | **보관함 이름** | 이름 적는 칸 (영어 소문자로 `pink-plan` 입력) |
| **Public** | **공개** | 인터넷 웹사이트로 띄우기 위해 공개 상태로 두기 |
| **Create repository** | **보관함 생성하기** | 맨 아래 초록색 큰 버튼 |
| **uploading an existing file** | **내 컴퓨터 파일 올리기** | 화면 중간 파란색 글씨 링크 |
| **Commit changes** | **저장 완료하기** | 파일 드래그 후 맨 아래 초록색 확인 버튼 |
| **Settings** | **설정 (톱니바퀴 ⚙️)** | 화면 상단 탭 메뉴 맨 오른쪽 |
| **Pages** | **웹사이트 만들기** | 설정(Settings) 들어간 후 왼쪽 메뉴 목록 |
| **Branch** | **가지 / 보관 구역** | `None`을 눌러서 `main`으로 바꾸기 |
| **Save** | **저장하기** | `main` 선택 후 바로 옆 버튼 클릭 |

> 💡 **꿀팁**: 크롬 브라우저 빈 곳을 마우스 오른쪽 클릭한 뒤 **[한국어로 번역]**을 누르면 깃허브 사이트 전체가 한글로 자동 번역되어 더욱 편리합니다!

## 📱 핑키 플랜 스케줄러 내 한글 버튼 풀이

스케줄러 앱 안의 모든 버튼은 친절한 한글로 표기되어 있습니다:

- **[☁️ 계정 연동 (두 PC 동기화)]**: 크롬에서 쓰는 이메일과 나만의 비밀번호(PIN)를 등록하여 다른 컴퓨터와 실시간 연결
- **[🔄]**: 최신 일정을 1초 만에 클라우드에서 다시 불러오는 즉시 동기화 버튼
- **[💾 파일 저장]**: 내 모든 일정 데이터를 컴퓨터에 안전하게 백업 파일로 보관
- **[📂 파일 열기]**: 백업해둔 일정 파일을 불러와서 원상 복구
- **[➕ 새 일정 등록]**: 제목, 날짜, 시간, 카테고리, 메모를 적는 상세 등록 모달창
- **[추가하기]**: 상단 한 줄 입력창에 적고 클릭하면 오늘 할 일로 1초 만에 등록
- **[오늘로 이동]**: 달력을 넘겨보다가 오늘 날짜로 단숨에 되돌아오는 버튼
- **[✏️ 수정] / [🗑️ 삭제]**: 각 일정 카드에 마우스를 올리면 나타나는 편집 버튼

## 🚀 두 대 이상의 PC에서 연동하는 방법

1. 크롬에서 `index.html`을 엽니다.
2. 우측 상단의 **[☁️ 계정 연동 (두 PC 동기화)]** 버튼을 누릅니다.
3. **이메일**과 **비밀번호 (4자리 이상)**를 입력하고 **[보안 동기화 시작]**을 클릭합니다.
4. 이제 다른 컴퓨터의 크롬에서도 똑같이 접속하여 **동일한 이메일과 비밀번호**를 넣으면 첫 번째 컴퓨터의 일정이 그대로 마술처럼 복호화되어 나타납니다!
